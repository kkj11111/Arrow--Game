# 一箭又一箭（Arrow Again）

一个基于 Python + Pygame 的点击式箭头解谜小游戏：观察箭头的方向与相互阻挡关系，按正确顺序点击，让所有箭头依次飞出棋盘。

## 游戏简介

棋盘中分布着朝上、下、左、右四个方向的箭头。点击一个箭头后：



* 若箭头朝向方向上到棋盘边界之间**没有其他箭头**，箭头会飞出棋盘并被消除；

* 若路径上存在其他箭头，箭头**不能飞出**，会晃动变红提示碰撞，并消耗一次失误次数；

* 清空本关全部箭头即通关，进入下一关；

* 失误次数耗尽则本关失败，可重新开始。

核心玩法参考微信小游戏《一箭又一箭》，仅参考玩法规则，代码、素材与关卡均为原创。

## 附加功能



* **得分 / 计时 / 三星评价**：通关后按剩余失误与用时计算得分，0 失误通关为 ★★★；

* **提示**：高亮一个当前可以飞出的箭头（金色光圈闪烁 2 秒）；

* **撤销上一步**：回退一次飞出或失误操作；

* **程序合成音效**：飞出、碰撞、通关、失败音效均为正弦波合成，无外部素材；

* **本地存档**：自动保存每关最高分与最高星级（save.json）；

* **随机挑战**：随机生成一个经过可解性验证的关卡；

* **AI 自动求解**：由求解器算出通关顺序并自动演示。

## 游戏操作说明



| 操作            | 说明                        |
| ------------- | ------------------------- |
| 鼠标左键点击箭头      | 选中箭头并尝试让其飞出               |
| 点击 “提示” 按钮    | 高亮一个当前可飞出的箭头              |
| 点击 “撤销” 按钮    | 回退上一步（飞出或失误）              |
| 点击 “自动求解” 按钮  | 由 AI 自动演示通关步骤（再次点击停止）     |
| 点击 “重新开始” 按钮  | 当前关卡恢复到初始状态               |
| 开始界面点击 “随机挑战” | 生成一个可通关的随机关卡              |
| 通关后点击 “下一关”   | 进入下一关（最后一关 / 随机挑战后返回开始界面） |
| 失败后点击 “重新开始”  | 重新挑战当前关卡                  |

界面说明：



* **开始界面**：游戏标题、玩法规则、“开始游戏”/“随机挑战” 按钮与历史成绩；

* **游戏界面**：顶部显示当前关卡、剩余箭头数量、失误次数、用时与 4 个功能按钮，中部为棋盘；

* **通关界面**：星级、得分、用时、失误与历史最高分；**失败界面**：提示与重新开始按钮。

## 项目说明



* **路径检测**：从箭头所在格沿其方向逐格前进，若在棋盘边界前遇到其他箭头则判定为 “被阻挡”，否则 “可飞出”。

* **关卡可解性自检**：`levels.is_solvable()` 通过贪心模拟验证关卡能否通关，程序启动时自动校验内置关卡，避免死锁。

* **AI 求解**：`levels.solve()` 在贪心模拟的同时记录消除顺序，即得到一条可通关的点击序列。

* **随机挑战**：`levels.generate_random_level()` 随机摆放箭头并用可解性验证过滤，保证生成关卡可通关。

* **动画反馈**：飞出时箭头沿方向移出屏幕；碰撞时箭头在原位左右 / 上下晃动并变红。
