# 一箭又一箭（Arrow Again）

一个基于 Python + Pygame 的点击式箭头解谜小游戏：观察箭头的方向与相互阻挡关系，按正确顺序点击，让所有箭头依次飞出棋盘。

## 游戏简介

棋盘中分布着朝上、下、左、右四个方向的箭头。点击一个箭头后：

- 若箭头朝向方向上到棋盘边界之间**没有其他箭头**，箭头会飞出棋盘并被消除；
- 若路径上存在其他箭头，箭头**不能飞出**，会晃动变红提示碰撞，并消耗一次失误次数；
- 清空本关全部箭头即通关，进入下一关；
- 失误次数耗尽则本关失败，可重新开始。

核心玩法参考微信小游戏《一箭又一箭》，仅参考玩法规则，代码、素材与关卡均为原创。

## 附加功能

- **得分 / 计时 / 三星评价**：通关后按剩余失误与用时计算得分，0 失误通关为 ★★★；
- **提示**：高亮一个当前可以飞出的箭头（金色光圈闪烁 2 秒）；
- **撤销上一步**：回退一次飞出或失误操作；
- **程序合成音效**：飞出、碰撞、通关、失败音效均为正弦波合成，无外部素材；
- **本地存档**：自动保存每关最高分与最高星级（save.json）；
- **随机挑战**：随机生成一个经过可解性验证的关卡；
- **AI 自动求解**：由求解器算出通关顺序并自动演示。

## 开发环境

- Python 3.10+（本项目在 Python 3.14.7 上开发与测试）
- pygame-ce 2.5.8（社区版，接口与官方 pygame 完全兼容）

> 说明：官方 `pygame` 目前没有适配 Python 3.14 的预编译安装包，因此本项目使用接口兼容的 `pygame-ce`，代码与官方 pygame 的用法一致。

## 安装和运行方法

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行游戏
python main.py
```

运行测试：

```bash
python -m unittest discover -s tests -v
```

## 游戏操作说明

| 操作 | 说明 |
| --- | --- |
| 鼠标左键点击箭头 | 选中箭头并尝试让其飞出 |
| 点击"提示"按钮 | 高亮一个当前可飞出的箭头 |
| 点击"撤销"按钮 | 回退上一步（飞出或失误） |
| 点击"自动求解"按钮 | 由 AI 自动演示通关步骤（再次点击停止） |
| 点击"重新开始"按钮 | 当前关卡恢复到初始状态 |
| 开始界面点击"随机挑战" | 生成一个可通关的随机关卡 |
| 通关后点击"下一关" | 进入下一关（最后一关 / 随机挑战后返回开始界面） |
| 失败后点击"重新开始" | 重新挑战当前关卡 |

界面说明：

- **开始界面**：游戏标题、玩法规则、"开始游戏"/"随机挑战"按钮与历史成绩；
- **游戏界面**：顶部显示当前关卡、剩余箭头数量、失误次数、用时与功能按钮，中部为棋盘；
- **通关界面**：星级、得分、用时、失误与历史最高分；**失败界面**：提示与重新开始按钮。

## 项目结构

```
arrow-again/
├── main.py               # Pygame 图形界面：界面/动画/音效/存档/附加功能
├── game_logic.py         # 核心逻辑：箭头/棋盘表示、路径检测、会话状态、撤销与计分
├── levels.py             # 关卡数据、可解性自检、AI 求解器、随机关卡生成
├── tests/
│   ├── test_core.py      # 核心逻辑测试（T01~T06 及撤销/计分/求解等）
│   └── test_smoke.py     # 界面冒烟测试（无窗口驱动完整流程）
├── screenshots/          # 游戏截图
├── render_check.py       # 截图生成脚本
├── requirements.txt
└── README.md
```
